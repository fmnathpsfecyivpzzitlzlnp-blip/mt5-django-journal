
start server:  python manage.py runserver --noreload

Чтобы сделать бэкап вручную, просто пишешь в консоль:
python manage.py backup_db
В папке проекта на диске D: автоматически появится папка backups,
а внутри нее сжатый файл с датой (например, my_db_backup_2026-06-23_15-00-00.sql).
